# typedstandards-host-template

A GitHub template repository for serving signed [Typed Standards](https://typedstandards.org) records from GitHub Pages under your own `did:key`, built with [`@typedstandards/host-core`](https://www.npmjs.com/package/@typedstandards/host-core). Copy it with "Use this template", replace the example record with your own, and its workflow checks that what Pages serves is what host-core builds and that every record verifies.
